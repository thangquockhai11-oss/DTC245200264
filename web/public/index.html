Các Dịch Vụ Hệ Thống

  • 🌐 Web Store: https://shop.local
  • 🗄️ phpMyAdmin: https://pma.local
  • 📊 Grafana Dashboards: http://localhost:3000
  • 📈 Prometheus: Internal port 9090 (cổng metrics: /metrics)
